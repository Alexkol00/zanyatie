# Проверка комплекта

Проверены 13 сценариев эталонной функции и три сценария командной строки. Заготовка ученика выдаёт ожидаемый NotImplementedError до реализации.

Кодовые ячейки эталонного блокнота выполнены последовательно в чистом пространстве Python; действие %%writefile воспроизведено записью файла. Проверены JSON-структура блокнотов, синтаксис Python и локальные ссылки README.

Полноценный запуск через ядро Jupyter, браузер Colab и сборка Docker в этой среде не выполнялись. Перед занятием преподавателю нужно проверить их на учебном компьютере по TEACHER.md.
