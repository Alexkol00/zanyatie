# Памятка преподавателю

## До занятия

Участники знают переменные, условия и цикл for; словари и функции объясняйте на примере. Возрастной ориентир — старшие школьники, колледж или вводный курс в вузе. Если основ Python нет, используйте два занятия.

Проверьте вход в Colab и интернет. На локальных ПК установите Python 3.10+, Git и Jupyter Notebook, Docker Desktop или Docker Engine. Не тратьте основное время занятия на установку Docker: могут потребоваться права администратора, виртуализация и перезапуск.

В терминале папки проекта:

```bash
python --version
git --version
python -m pip install -r requirements-notebook.txt
jupyter notebook
```

В отдельном терминале, при запущенном Docker:

```bash
docker version
docker pull python:3.12-slim
docker run --rm hello-world
```

Если окружение Python управляется системой, установите Notebook в отдельное виртуальное окружение по правилам вашего учебного класса. Для самой миссии сторонние пакеты не нужны.

## Решение и демонстрация

`mission.py` в корне — намеренно незавершённая заготовка. Не используйте её как готовую демонстрацию. Эталон:

```bash
python solutions/mission.py
python check.py solutions/mission.py --final
docker build -f solutions/Dockerfile -t mars-mission-solution .
docker run --rm mars-mission-solution --battery 55 --max-risk 4 --reserve 10
```

Результат: «Каньон», остаток 10. Эталон содержит исходные три маршрута и финальный резерв; дополнительный маршрут ученики добавляют самостоятельно. Сборка решения выполняется **из корня репозитория**, не из `solutions`.

Для просмотра готового блокнота откройте `solutions/mission_solution.ipynb` в отдельной папке или Colab. Его ячейка записи тоже создаёт `mission.py` в текущей папке: не запускайте поверх незавершённой работы ученика.

## Ключевые ответы

- Изменение текста ячейки не меняет переменную до запуска.
- При 60/4 выбирается Каньон, при 60/2 — Равнина, при 40/4 — None.
- `<` вместо `<=` ломает случай точного равенства (45/4 и 35/7).
- С пустым списком результат None; при одинаковом расходе — первый маршрут.
- Финальная проверка энергии: `route["energy"] + reserve <= battery`.
- При исходных маршрутах 55/4/10 даёт Каньон, 54/4/10 — None.
- После добавления Лавовой трубы 55/4/10 выбирает её, остаётся 25.
- Git фиксирует локальную историю. GitHub размещает репозиторий; коммит без push не отправляется туда.
- Образ — подготовленная основа, контейнер — экземпляр её запуска. COPY не связывает файл с локальной копией автоматически.

## Типичные затруднения

| Симптом | Причина / действие |
|---|---|
| NotImplementedError | Не завершена choose_route; это ожидаемая заготовка |
| После исправления всё по-старому | Выполнить ячейку %%writefile и ячейку runpy заново |
| Правки файла исчезли | Старая ячейка %%writefile перезаписала файл; восстановить из Git, если правки были закоммичены |
| Команда python не найдена | Использовать установленную команду python3 или настроить PATH |
| git не узнаёт автора | Выполнить две локальные команды git config из инструкции |
| Cannot connect to Docker daemon | Запустить Docker и проверить доступ пользователя |
| COPY не находит файл | Выполнить сборку из корня проекта |
| Не скачивается образ | Проверить сеть; заранее загрузить образ на учебных ПК |
| Colab сбросился | Загрузить сохранённый .ipynb и выполнить сначала; временные файлы могли исчезнуть |
| Нет Docker на ПК ученика | Провести общую демонстрацию и оценить понимание отдельно |

## Оценивание и доступ к ответам

Рубрика на 10 баллов находится в README и блокноте. Решения в публичном репозитории не являются секретными. Для контрольной работы используйте отдельную ученическую копию без решений; для практикума разрешите смотреть подсказки после собственной попытки.

Перед занятием проверьте Docker на реальном оборудовании. В комплекте программные проверки не требуют Docker; они не заменяют пробную сборку контейнера на компьютере преподавателя.
